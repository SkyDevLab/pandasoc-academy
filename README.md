# PandaSOC Academy 🐼

A responsive, static, interactive learning site for beginner SOC and incident-response concepts, using the cream-and-bamboo visual theme of Panda Forensics.

## Learning features
- Six expanded modules: triage, validation/scoping, indicators, containment, recovery, reporting and lessons learned.
- In-module scenario checks and locally stored completion progress.
- Seven-step incident-response playbook.
- Interactive indicator explorer (hash, IP address, identity and behaviour).
- Four fictional SOC case files with feedback.
- A 15-question scored knowledge check with answer explanations and retry.
- Pyramid of Pain visual, field notes and FAQ.
- Responsive layout, panda mascot, dark mode, reduced-motion support and no build step.

## Run locally
Open `index.html` in a modern browser. No package manager or build process is required.

## Deploy to GitHub Pages
This repository contains a GitHub Actions Pages workflow. Set **Settings → Pages → Build and deployment → Source** to **GitHub Actions**, then check the Actions tab for a successful deployment.

## Educational note
This is a learning aid with fictional examples, not operational security advice for a live incident. Follow your organisation's approved incident response plan, evidence-handling rules, authority boundaries and reporting requirements.
