# PandaSOC Academy 🐼

A responsive, static, interactive beginner's guide to SOC incident response.

## Features
- Panda mascot and monochrome/green visual theme
- Five expandable lessons with locally saved progress
- Interactive alert triage scenario with feedback
- Pyramid of Pain visual
- Five-question quiz with instant feedback and score
- Dark mode
- Responsive layout for desktop and mobile
- No build step or dependencies; suitable for GitHub Pages

## Run locally
Open `index.html` in a modern browser.

## Deploy to GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save.
4. Wait for the Pages deployment to finish. The expected site URL is `https://skydevlab.github.io/pandasoc-academy/`.
5. Verify the Actions/Pages status and open the URL. The expected URL is not proof of a successful deployment until GitHub Pages reports it published.

## Educational note
This is a learning aid with fictional examples, not operational security advice for a live incident. Always follow your organisation's incident response plan and the evidence and terminology required by your course.
